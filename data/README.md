# Данные проекта

Данные учебные, из базы курса BI-аналитика. Доступы не публикуются.
Схема: `marketplace` (PostgreSQL), 7 таблиц, период заказов 01.06.2024–31.05.2025.

## Таблицы

### Таблица `categories` — категории товаров
Содержит список категорий, которым принадлежат продукты.
Примечание:
* Выбран нетипичный тип данных для `parent_category_id`
* `name` содержит большое количество дублей, при построении отчета ориентироваться строго на `category_id`
* `parent_category_id` ссылается на `category_id`, иерархия целостна
* Среди значений `name` встречается строка 'None' - ловушка для IS NULL-фильтров (2 строки)

| Столбец              | Тип         | Ключ | NOT NULL | Описание                                                                        |
| -------------------- | ----------- | ---- | -------- | ------------------------------------------------------------------------------- |
| `category_id`        | int4        | PK   | true     | уникальный ID категории                                                         |
| `name`               | varchar(50) |      | false    | название категории                                                              |
| `parent_category_id` | float4      |      | false    | ID родительской категории (→ categories.category_id); NULL — корневая категория |

### Таблица `orders` — заказы
Содержит общую информацию по заказу.
Примечание:
* Выбран нетипичный тип данных для `buyer_id`
* Таблица хранит текущее состояние заказа, при его изменеии строка перезаписывается. Теряется возможность восстановления хронологии
* Воронка на дашборде возможна только по срезу на текущий момент выгрузки
* Для `total_amount` лучше использовать тип данных numeric - точный тип


| Столбец        | Тип         | Ключ | NOT NULL | Описание                         |
| -------------- | ----------- | ---- | -------- | -------------------------------- |
| `order_id`     | varchar(50) | PK   | true     | уникальный ID заказа             |
| `buyer_id`     | varchar(50) | FK   | false    | ID покупателя  (→ users.user_id) |
| `order_date`   | timestamp   |      | false    | дата создания заказа             |
| `status`       | varchar(50) |      | false    | статус заказа                    |
| `total_amount` | float4      |      | false    | общая сумма заказа               |



### Таблица `order_items` — товары в заказах
Содержит позиции товаров, которые были фактически проданы в конкретных заказах. Каждая строка — это товар, который был включён в заказ, с указанием количества и цены на момент покупки. 
* Для `price_at_order_time` лучше использовать тип данных numeric - точный тип
* Есть расхождения в сумме заказов в таблице orders и order_items, которые вызваны разницей в порядке округления при расчёте сумм: orders.total_amount, вероятно, рассчитывался с округлением на другом этапе, чем сумма позиций в order_items. Остаточная разница ±0.05 руб. соответствует половине копейки на позицию и является артефактом округления, а не ошибкой данных.

| Столбец               | Тип         | Ключ | NOT NULL | Описание                                |
| --------------------- | ----------- | ---- | -------- | --------------------------------------- |
| `order_item_id`       | varchar(50) | PK   | true     | уникальный ID позиции заказа            |
| `order_id`            | varchar(50) | FK   | false    | ID заказа (→ orders.order_id)           |
| `product_id`          | varchar(50) | FK   | false    | ID товара (→ products.product_id)       |
| `quantity`            | int4        |      | false    | количество единиц товара в позиции      |
| `price_at_order_time` | float4      |      | false    | цена товара на момент оформления заказа |





### Таблица `products` — товары
Содержит каталог всех товаров маркетплейса, которые могут быть выставлены продавцами. 

| Столбец          | Тип         | Ключ | NOT NULL | Описание                                    |
| ---------------- | ----------- | ---- | -------- | ------------------------------------------- |
| `product_id`     | varchar(50) | PK   | true     | уникальный ID товара                        |
| `title`          | varchar(50) |      | false    | название товара                             |
| `description`    | varchar(50) |      | false    | описание товара                             |
| `category_id`    | int4        | FK   | false    | категория товара (→ categories.category_id) |
| `price`          | float4      |      | false    | цена товара                                 |
| `stock_quantity` | int4        |      | false    | количество товара в наличии                 |
| `seller_id`      | varchar(50) |      | false    | ID продавца                                 |

### Таблица `reviews` — отзывы
Содержит отзывы пользователей.

| Столбец       | Тип         | Ключ | NOT NULL | Описание                          |
| ------------- | ----------- | ---- | -------- | --------------------------------- |
| `review_id`   | varchar(50) | PK   | true     | уникальный ID отзыва              |
| `user_id`     | varchar(50) | FK   | false    | ID пользователя (→ users.user_id) |
| `product_id`  | varchar(50) |      | false    | ID товара (→ products.product_id) |
| `rating`      | int4        |      | false    | оценка товара                     |
| `comment`     | text        |      | false    | текст отзыва                      |
| `review_date` | timestamp   |      | false    | дата создания отзыва              |

### Таблица `transactions` — транзакции
Содержит записи платежей и возвратов пользователей.
Примечание:
* Таблица по какому-то причине не привязана к таблице с заказами
* В поле `transaction_type` помимо `payment` и `refund` встречается `payout`

| Столбец          | Тип         | Ключ | NOT NULL | Описание                                                  |
| ---------------- | ----------- | ---- | -------- | --------------------------------------------------------- |
| transaction_id   | varchar(50) | PK   | true     | уникальный ID транзакции                                  |
| user_id          | varchar(50) | FK   | false    | ID пользователя (→ users.user_id)                         |
| amount           | float4      |      | false    | сумма платежа, может быть отрицательной в случае возврата |
| transaction_type | varchar(50) |      | false    | тип транзакции (`refund` или `payment`)                   |
| transaction_date | timestamp   |      | false    | дата платежа или возврата                                 |

### Таблица `users` — пользователи
Содержит информацию обо всех пользователях маркетплейса. 
Примечание:
* `is_active` не ясен принцип работы поля
* На один email может быть до 18 регистраций. По какому-то причине это не проверяется при регистрации нового пользователя. 

| Столбец             | Тип         | Ключ | NOT NULL | Описание                                     |
| ------------------- | ----------- | ---- | -------- | -------------------------------------------- |
| `user_id`           | varchar(50) | PK   | true     | уникальный ID пользователя                   |
| `name`              | varchar(50) |      | false    | имя пользователя                             |
| `email`             | varchar(50) |      | false    | электронный адрес                            |
| `phone`             | varchar(50) |      | false    | телефон                                      |
| `user_type`         | varchar(50) |      | false    | тип пользователя (`buyer` или `seller`)      |
| `registration_date` | timestamp   |      | false    | дата регистрации                             |
| `is_active`         | bool        |      | false    | активность пользователя (`true` или `false`) |
